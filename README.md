Bài Tập Kiểm Thử JUnit - Phân Tích Điểm Số Học Sinh

- Họ tên: Đào Tiến ĐạtĐạt
- MSSV: BIT230081
- Lớp: SOFT2SOFT2

Mô Tả Dự Án

Chương trình phân tích điểm số học sinh bằng Java với đầy đủ test tự động.
Chức năng:
1. Đếm số học sinh giỏi (điểm >= 8.0)
2. Tính điểm trung bình (chỉ tính điểm hợp lệ từ 0-10)

Cách Chạy
run-test.bat
Kết quả: 18 tests thành công
Các Test Cases (18 tests)

Đếm học sinh giỏi (8 tests):
- Danh sách bình thường
- Có điểm không hợp lệ (< 0 hoặc > 10)
- Danh sách rỗng / null
- Điểm biên (0, 8.0, 10.0)
- Toàn điểm không hợp lệ
- Toàn học sinh giỏi

Tính điểm trung bình (10 tests):
- Danh sách bình thường
- Có điểm không hợp lệ
- Danh sách rỗng / null
- Chỉ có điểm 0 hoặc 10
- Điểm biên
- Một điểm hợp lệ
- Kiểm tra độ chính xác
